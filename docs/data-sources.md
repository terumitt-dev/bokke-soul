## 選ぶ条件

- 再配布・改変が許可されているライセンス (CC BY など)
- 数十MB以下で、ダウンロードできる
- LAS / LAZ / PLY / E57 のいずれか

## 探す先の候補

- [G空間情報センター](https://www.geospatial.jp/)
- [国土交通データプラットフォーム](https://www.mlit-data.jp/)
- [Project PLATEAU](https://www.mlit.go.jp/plateau/)
- 各自治体のオープンデータ (BODIK など)
