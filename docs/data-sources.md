#### 使っているタイル

08OF3006 を中心に、東西南北の隣のタイルを使う (2019 年、標高グリッド、400m x 300m。隣どうしは、地形が連続する)。取得日は 2026-11-23。

| タイル | 中心に対する位置 | 場所 (大字、国土地理院の逆ジオコーダー) |
|---|---|---|
| 08OF3006 | 中心 | 河津町梨本 |
| 08OF3005 | 西 | 河津町梨本 |
| 08OF3007 | 東 | 河津町川津筏場 |
| 08OF3016 | 南 | 河津町梨本 |
| 08OF2096 | 北 | 河津町梨本 |

タイル番号の求め方は、東西は文字と 2 桁目、南北は行で、同じ 300m x 400m の区画。隣のタイルの番号は、`08OF3006` の末尾の 2 桁 (行, 列) を 1 つずつ動かして求める (繰り上がり・繰り下がりに注意)。

データの全体像と形式は https://github.com/aigidjp/opendata_virtualshizuoka を参照。

## 選ぶ条件

- 再配布・改変が許可されているライセンス (CC BY など)
- 数十MB以下で、ダウンロードできる
- LAS / LAZ / PLY / E57 のいずれか

## 探す先の候補

- [G空間情報センター](https://www.geospatial.jp/)
- [国土交通データプラットフォーム](https://www.mlit-data.jp/)
- [Project PLATEAU](https://www.mlit.go.jp/plateau/)
- 各自治体のオープンデータ (BODIK など)
