#### 使っているタイル

08OF3006 を中心に、東西南北の隣のタイルを使う (2019 年、標高グリッド、400m x 300m。隣どうしは、地形が連続する)。取得日は 2026-11-23。

| タイル | 中心に対する位置 | 場所 (大字、国土地理院の逆ジオコーダー) |
|---|---|---|
| 08OF3006 | 中心 | 河津町梨本 |
| 08OF3005 | 西 | 河津町梨本 |
| 08OF3007 | 東 | 河津町川津筏場 |
| 08OF3016 | 南 | 河津町梨本 |
| 08OF2096 | 北 | 河津町梨本 |

タイル番号の求め方は、東西は文字と 2 桁目、南北は行で、同じ 300m x 400m の区画。隣のタイルの番号は、`08OF3006` の末尾の 2 桁 (行, 列) を 1 つずつ動かして求める (繰り上がり・繰り下がりに注意)。

### 地面の色 (航空写真)

地面の色は、国土地理院の航空写真から付ける (2026-11-28)。変換した地形 (GLB) ごとに、`tools/fetch_aerial.py` が写真を切り出して、同じ名前の `.jpg` にする。ゲームは、実行中に写真を取りに行かず、この `.jpg` を読む。

| 項目 | 内容 |
|---|---|
| 名称 | 地理院タイル「全国最新写真 (シームレス)」(ズームレベル 18) |
| 提供元 | 国土地理院 |
| URL | https://maps.gsi.go.jp/development/ichiran.html (タイルの URL: `https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg`) |
| 利用条件 | 出典の明示で、申請なしで使える (基本測量成果以外で、出典の記載のみで利用可能なもの)。出典は、「国土地理院」または「地理院タイル」 |
| 取得日 | 2026-11-28 |
| 加工 | 測量座標 (EPSG:6676) の範囲に合わせて切り出し (1 ピクセル 0.5 m、上が北)。ゲームの色づけ (彩度を落とす) は、画面で行う |
| 置き場 | `data/processed/<タイル>.jpg` (変換後のデータなので、リポジトリには含めない)。取ったタイルは `data/cache/` にためる (これも含めない) |
| 出典表示 | ゲームのクレジットに載せている |

注意: この写真は、「電子国土基本図 (オルソ画像)」、「森林 (国有林・民有林) の空中写真 (林野庁)」、「地方公共団体等の空中写真」、「簡易空中写真」、「国土画像情報」から作られている。個別の出所の表示が要る画像 (Landsat-8、GRUS) は、沖縄の一部と、この地域とは別の範囲に限られる (一覧ページの備考より)。**公開する前に、この地域の写真の出所と、表示の条件を、もう一度確かめる。**

### 篝火の名前 (地名)

篝火の名前は「<名前>の篝火」とし、その篝火の近くの、実在する道、歩道、停留所の名前を使う (2026-11-23 決定)。国土地理院の逆ジオコーダーが返すのは大字までで、字 (小字) の名前は、法務省の登記所備付地図でも取れなかったため (公共座標の地図が山の中にない)。

| 項目 | 内容 |
|---|---|
| 名称 | OpenStreetMap |
| 提供元 | OpenStreetMap contributors |
| URL | https://www.openstreetmap.org/copyright |
| ライセンス | ODbL 1.0 (出典の表示が必要) |
| 取得日 | 2026-11-23 (Overpass API で、篝火の位置の周り 800 m の名前を調べた) |
| 出典表示 | 「© OpenStreetMap contributors (ODbL)」。ゲームのクレジットに載せている |

| タイル | 篝火の名前 | 由来 |
|---|---|---|
| 08OF3005 (西) | ウグイス歩道 | 篝火から約 87 m の歩道 |
| 08OF3006 (中心) | 寒天林道 | 篝火から約 274 m の林道 |
| 08OF3016 (南) | 八丁池口 | 篝火から約 326 m のバス停 (八丁池への登り口) |
| 08OF3007 (東) | 寒天林道・東 | 近くに目立つ名前がないので、寒天林道 (中心) から見た方角 |
| 08OF2096 (北) | 寒天林道・北 | 同上 |

神社、墓地、信仰の場の名前は使っていない。名前を変える時は、そのことを確かめる。

データの全体像と形式は https://github.com/aigidjp/opendata_virtualshizuoka を参照。

## 選ぶ条件

- 再配布・改変が許可されているライセンス (CC BY など)
- 数十MB以下で、ダウンロードできる
- LAS / LAZ / PLY / E57 のいずれか

## 探す先の候補

- [G空間情報センター](https://www.geospatial.jp/)
- [国土交通データプラットフォーム](https://www.mlit-data.jp/)
- [Project PLATEAU](https://www.mlit.go.jp/plateau/)
- 各自治体のオープンデータ (BODIK など)
