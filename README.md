# bokke-soul

点群(レーザースキャン)の世界を歩く、ソウルライク風の探索ゲーム。

## 名前の由来

**bokke** + **soul** の組み合わせです。

- **bokke(ぼっけ)**: 薩摩の言葉「ぼっけもん」から。向こう見ずで、怖いものに飛び込んでいく人のこと。暗がりの中を一歩ずつ進むプレイヤーの姿と重ねています。
- **soul(ソウル)**: ダークソウルのような、篝火で休みながら少しずつ世界を進む探索ゲームの系譜(ソウルライク)から。

鹿児島ゆかりの言葉と、遊びの系譜を並べた名前です。

## 概要

建設・測量の現場で使われる点群データを素材にして、歩き回れる世界を作ります。

- 点群をそのままではなく、掃除・メッシュ化・軽量化して使う
- 篝火は測量基準点。休むと周囲の点がくっきり整い、歩いた場所は点で埋まっていく
- 床の下に落ちた時は「位置を見失いました。再スキャン中…」と、最後に休んだ篝火へ戻る

当面の目標は「ローカルで起動して、一人称で歩き回れる状態」です。

## 構成

```
game/        Godot プロジェクト
tools/       点群の掃除・メッシュ化・軽量化スクリプト
docs/        データの出典、ライセンス、加工手順
data/raw/    元の点群(リポジトリには含めない)
```

## 起動

```
godot --path game
```

タイトル画面が出て、「はじめる」で世界を歩けます。何も指定しなければ、リポジトリに入っている人工のサンプルの世界を使います。変換したデータで遊ぶ時は、世界の場所を渡します。

```
godot --path game -- --world=/絶対パス/world.glb
```

タイトル画面の隅とクレジットには、世界のデータの出典が出ます (データの隣の `.json` から読みます。`tools/README.md` の `--credit` を参照)。

## 必要なもの

- [Godot](https://godotengine.org/) 4.x
- [CloudCompare](https://www.cloudcompare.org/)(点群の目視確認用)

## データについて

使用するデータの出典とライセンスは `docs/` に記載します。元の点群は再配布条件があるため、リポジトリには含めません。

## 昼夜、天気、設定

世界は時刻に合わせて、空、霧、太陽の光が変わります。天気は、晴れ、曇り、砂塵、砂嵐の 4 種類で、3 時間ごとに時刻から決まる疑似乱数で切り替わります (ネットワークは使いません)。同じ種 (seed) なら、同じ瞬間は、世界のどこでも同じ天気になります (実時間の方式では、天気はタイムゾーンによらず UTC で決まります。昼夜は、パソコンの時刻に合わせます)。設定は `user://settings.cfg` から読みます。ファイルがない、または値が不正な時は、既定値で動きます。

```
[time]
mode="accelerated"        ; accelerated = 1 日を短くする / realtime = 実時間 / fixed = 時刻を止める
day_length_minutes=60.0   ; accelerated の時、1 日 (昼夜が一巡) を何分にするか
start_hour=7.0            ; accelerated の時、始まる時刻 (0〜24)
fixed_hour=12.0           ; fixed の時の時刻 (0〜24)

[weather]
enabled=true              ; false なら、いつも晴れ
seed=0                    ; 天気の並びを決める種
```

macOS では `~/Library/Application Support/Godot/app_userdata/bokke-soul/settings.cfg` です。

開発ビルドでは、`T` キーで時刻を 3 時間ずつ飛ばし、`Y` キーで天気を「自動 → 晴れ → 曇り → 砂塵 → 砂嵐」と切り替えられます (画面の左上に時刻と天気が出ます)。製品ビルドでは無効です。
